# Lyquix WordPress Child Theme

`@version 3.2.0`

Child theme for the [Lyquix WordPress Theme](https://github.com/Lyquix/wp_theme_lyquix). This is where all project-specific customization, styling, scripting, and build tooling lives.

## Getting Started

```bash
cd wp-content/themes/lyquix-child
nvm use 18
bun install    # Installs dependencies and runs postinstall to scaffold files
bun run watch  # Starts development with auto-compilation and LiveReload
```
